# Pink Dream

Unity 2022.3.62f3 · 2D interactive prototype.

## 独立关卡场景

- `Assets/Scenes/Start.unity`：父母查看 B 超的开始界面。拖动放大镜找到胎儿，发现 START 并保持至少 1 秒后进入“出生前”。
- `Assets/Scenes/Level01_BeforeBirth.unity`：出生前。可以直接打开并运行，跳过开始界面。
- `Assets/Scenes/Transition_Blank.unity`：各关切换共用的独立空镜转场，颜色与游戏背景一致。
- `Assets/Scenes/Level02_FirstBirthday.unity`：第二关，婴儿周岁抓周。只有婴儿和物品，没有父母。
- `Assets/Scenes/Level03_ChildhoodPacking.unity`：第三关，童年整理书包。操控女孩收好全部粉色物品。
- `Assets/Scenes/Level04_AdolescencePiercing.unity`：第四关，青少年时期。黑灰色朋克风格，操控女孩给自己打耳洞。
- `Assets/Scenes/Level05_ComingOfAge.unity`：第五关，成年礼。自由组合蛋糕装饰，拉绳后庆祝成年。
- `Assets/Scenes/SampleScene.unity`：保留原来的单人布娃娃原型。

在编辑器当前仍打开旧的 `SampleScene` 时，Play 会从 `Start` 启动；直接打开其他关卡时，Play 仍单独运行该关卡。
也可以通过菜单 `Pink Dream → 打开 Start 开始界面` 切换到开始场景。界面文字使用已导入的中文字体资源，随场景一起加载。
正式流程只显示操作提示、进度/完成状态提示，以及必要的 START 入口。对白框、关卡标题、游戏标题、物品名称标签、人物态度和结尾祝福文字均已从场景中删除；视觉庆祝及返回 Start 的操作提示保留。

Start 进入第一关、每一关完成后进入下一关，以及结尾返回 Start，都采用“当前画面淡出 → 同背景色的独立空白场景 → 下一画面淡入”的转场。各关的完成展示时间保持原设置，之后默认用 0.7 秒淡出、在 `Transition_Blank` 停留 0.8 秒，再用 0.7 秒淡入。转场期间暂停拖拽与开始判定，下一关可见后再恢复操作。
每个可玩场景的 `统一转场 · 淡出与淡入时间设置` 对象中可调整转场时间，遮罩已预放在场景中，编辑模式下透明；第一关已有的完成演出仍使用原来的画面淡出时间。空白停留时间仍在 `Transition_Blank` 的原有组件中调整。各关仍是独立 Scene，直接打开某一关不会强制跳到其他场景。

### Start 的放大镜发现玩法

开始场景中只有父亲、母亲、B 超屏幕和放大镜，不含医生。放大镜初始独立散放在电视机右下方，父母均不持镜。玩家可以直接拖动镜片或手柄，把它放到 B 超屏幕上，真实放大该位置的图像；也可以拖动人物的手到握柄处，主动拿起后再带动镜子。放大镜没有被人物拿起时，拖动它不会牵动人物。
放大镜对准胎儿时，镜片内显示 START。保持位置稳定至少 1 秒后自动进入“出生前”，无需额外点击。离开目标、明显移动或切出 Game 视图会重置停留计时；松手后保持在正确位置也会继续计时。
所有人物、B 超纹理、胎儿几何、镜片、采样摄像机和文字都已保存为场景对象或工程资源，运行时不生成人物。`Start · 发现与停留时间设置` 对象可修改放大倍率、目标允许距离、停留时长（最低 1 秒）及稳定判定容差。
放大镜使用预放摄像机和 RenderTexture，仅捕捉 B 超视觉层，父母、镜框和提示文字不会递归出现在镜片中。布娃娃的四肢牵引、停止即冻结的规则及第一关内容保持不变。
放大镜的手柄和握持点已镜像到母亲一侧，镜片朝向 B 超屏幕；镜片影像与 START 文字保持正常方向。

人物、蛋糕、刀、顶部提示、礼花和气球都直接保存在各自场景里，可在编辑模式下选中和修改。
顶部提示为“手牵手，一起握刀切开蛋糕”。先拖动父母的手靠近彼此，牵手后将两人的手移到刀柄圆圈处，随后向下拖动刀或牵着的手切开蛋糕。
也可以在牵手后，把刀柄拖到两人的手上。完成切割后，白色蛋糕分开并露出粉色内馅，礼花从左右两侧向中间斜上方喷出，随后受重力影响下落、翻转；气球从画面底部陆续放飞，以不同速度上升，并向左右飘散、轻轻摆动。默认保持 1 秒后，用 0.85 秒自然减淡消失，随后直接淡出到与游戏背景同色的独立空镜，再进入第二关“婴儿周岁抓周”，中间不显示或等待对白。

关卡行为由 `BeforeBirthLevel` 管理，人物依旧调用原有 `PoseRagdollModel`，不增加重力、惯性或自动摆动。
`出生前 · 关卡交互` 对象的 Inspector 中可修改牵手距离、握刀距离、蛋糕分离距离、气球速度，以及各物品和效果的场景引用。

`出生前 · 完成演出与时间设置` 对象上可以修改礼花/气球停留时间（默认 1 秒）、减淡时间和画面淡出时间。
该对象还提供礼花发射速度、每秒喷出数量、起喷数量和重力，以及气球上升速度、速度差异、横向飘散速度与轻摆幅度。当前礼花速度为 7.5，每个喷口每秒喷出 18 个、起喷 12 个。气球由完成演出统一驱动，原关卡组件的气球速度仅用于未接入完成演出的旧效果。
在 `Transition_Blank` 场景中，`空白转场 · 停留时间与下一关设置` 对象可以修改空镜时长（默认 0.8 秒）。正常流程由完成关卡传入下一关；Inspector 中的下一关场景名只在单独打开该空镜场景时作为默认目标，把该默认目标留空时，单独运行会停留在空镜中。
礼花、气球和转场遮罩均已预放在编辑场景中，揭晓前隐藏，运行时不会生成新的角色或界面对象。各关在自己的 Scene 中编辑。

### 第二关 婴儿周岁抓周

直接打开 `Assets/Scenes/Level02_FirstBirthday.unity` 可单独编辑、运行第二关，或从第一关完成后的空镜进入。
场景中只有大头短四肢、坐姿的婴儿布娃娃，以及剪刀、电脑鼠标、画笔、红包和尤克里里五种抓周物品。人物和物品直接保存在场景中，运行时不再生成，人物头顶没有身份文字。
拖动婴儿任意部位带动手接触物品，或直接把物品送到任一只手上。手掌碰撞体与物品实际接触时才算抓住，不会靠近就吸附，抓住后保留物品的接触位置。抓到任意一件都判定通关，停留 2 秒后进入第三关“童年整理书包”。选择只用于本关通关，不写入偏好、职业或后续关卡分支。
五种物品的多边形碰撞体贴合可见外形，包括倾斜笔杆、琴身与琴颈、剪刀刃及指环，指环孔和物品周围的空白区域不参与抓取判定。碰撞体已保存在场景中，可在编辑模式下修改。
`周岁抓周 · 任意物品即可通关` 对象可修改完成后的展示时间（默认 2 秒）、下一关场景名和五种物品的引用。婴儿采用同一套冻结关节求解，头颈继续与躯干对齐；体型参数用于婴儿比例，现有成人保持默认比例和原玩法。

### 第三关 童年整理书包

直接打开 `Assets/Scenes/Level03_ChildhoodPacking.unity` 可单独编辑第三关；第二关抓到物品后也会进入这里。场景预放童年比例的女孩、粉色书包，以及粉色布娃娃、铅笔、橡皮、笔记本和故事书，不含父母。物品均为几何素材，碰撞体贴合可见形状。
拖动女孩，让任一只手真正接触物品后拿起，保留实际接触位置，不吸附。可以继续拖动人物，也可以拖动已经拿在手中的物品来带动手臂；每只手最多拿一件。物品完整进入书包标示区域后松手才算收好，松手时仍在包外的物品继续拿在手上。收好的物品保持放置位置，藏在书包前袋后方，不能重复计数。
全部五件收好后显示完成提示，默认停留 2 秒，再进入第四关“青少年时期”。`童年 · 整理书包交互与时间设置` 可修改物品引用、完成停留时间和下一关；书包的 `书包内部 · 完整放入后松手` 对象可修改放置区域。女孩继续使用原有冻结布娃娃求解，停止拖动立即保持姿势，头颈与躯干对齐。

### 第四关 青少年时期

直接打开 `Assets/Scenes/Level04_AdolescencePiercing.unity` 可独立编辑第四关，或从第三关收好书包后进入。女孩穿黑色衣服，配黑色短发、颈圈、腰带铆钉和银链；周围散放黑银穿耳器、铆钉手环、黑灰耳机、黑色涂鸦本、厚底靴和银链。主题通过人物造型与物品呈现，界面只显示穿耳操作及进度提示，背景继续沿用整个游戏的统一颜色。
拖动女孩，让任一只手真正碰到穿耳器后拿起，物品保留接触时的位置，不吸附。拿起后也可以直接拖动穿耳器带动手臂。把穿耳器的银色前端带到可见耳垂处，实际接触后松手，完成这一侧的耳洞并显示对应耳饰。两侧可按任意顺序完成，完成第一侧后继续操作另一侧，重复碰触已完成的一侧不会重复计数；器身、手掌或头部其他位置接触均不会直接通关。两侧均完成后才判定通关，停留 2 秒，再进入第五关“成年礼”。
`青少年 · 穿耳交互与完成时间设置` 可修改完成停留时间、下一关和对象引用。耳垂碰撞体在女孩头部的左右耳下面，穿耳器的接触点在物品下面，均与可见几何大小一致，可直接在场景中调整。耳饰预放在耳垂下，初始隐藏；运行时不会生成人物或物品。角色继续采用同一套冻结布娃娃求解及固定头颈规则。

### 第五关 成年礼：亲手组合未来

直接打开 `Assets/Scenes/Level05_ComingOfAge.unity` 可独立修改第五关，第四关完成后也会进入这里。女孩、蛋糕、五件物品、五种隐藏的蛋糕装饰、拉绳、烛火、庆祝目标姿势、开心表情、彩色礼花和气球均已预放，运行时不生成人物或装饰。
拖动女孩，让手实际接触物品后拿起，拿取过程保留接触位置，不吸附。再把拿着物品的手带到蛋糕旁的触发区域，物品自动变成装饰：画笔变黄色蜡烛；种子长出绿色小花；星星漂浮在蛋糕上方；蝴蝶结变粉色奶油装饰；相机变闪光小糖片。两只手各可拿一件，每种装饰可添加一次，允许任意组合，不要求全部集齐，不记录职业或固定人生分支。
玩家自行向下拉动右侧拉绳表示装扮完毕，随后点亮蛋糕和蜡烛，从两侧向中间喷洒彩色礼花，彩色气球从底部放飞并向各方向飘动。女孩从当前姿势平滑抬起双手、微笑并轻轻跃起一次，画面中不显示祝福或感想文字。装扮阶段仍使用原来的冻结求解，只有明确触发庆祝后才自动做动作；动作全程保持关节连接、头颈与躯干对齐。
礼花与气球默认保持 2 秒，再用 1.2 秒减淡；点亮的蛋糕、选中的装饰和开心姿势保留。庆祝动作及效果均结束后显示“点击空白处，返回 Start 重新开始游戏。”；松开拉绳后需重新点击画面空白处才返回，点击女孩、蛋糕、物品或提示文字不会返回。回到 Start 后，父母、放大镜及开始判定恢复初始状态，可以重新开始整段游戏，关卡物品与进度也随重新加载重置。
`成年礼 · 自由组合与拉绳交互` 可修改装饰引用、蛋糕触发范围、拉绳行程和装饰出现时间；`成年礼 · 点亮与彩色庆祝设置` 可修改庆祝动作时间、礼花速度和数量、气球速度、保持及减淡时间。庆祝姿势在 `庆祝目标姿势 · 可编辑参数` 中，身体位置及各部位角度可单独调整。

## 几何布娃娃原型

打开 `Assets/Scenes/SampleScene.unity`，编辑模式下即可看到并选中完整角色，点击 Unity 的 Play 开始拖拽。
鼠标左键按住头、躯干、手臂、手、腿或脚进行拖拽。关节会牵动相邻肢体，持续拉动时可以带动整个人。
抓取位置不会跳到肢体中心。鼠标停止移动时，当前姿势立即固定；松开后继续保持。
仅移动鼠标、点击空白处、失去窗口焦点或鼠标离开 Game 视图均不会让布娃娃自行运动。

角色由圆形、胶囊和矩形组成，无外部美术资源。几何对象、碰撞体和显示引用直接保存在场景中，运行时只绑定现有对象，不再生成角色。
`PoseRagdollModel` 以刚性部件和关节约束处理拖拽，没有重力、速度、惯性或每帧物理模拟。
头部与躯干保持固定的颈部距离和一致朝向，随躯干一起移动和转动；拖动头部同样会带动身体，不再通过自由颈关节弯折。四肢的关节牵引方式保持不变。
`FrozenRagdoll` 负责鼠标拾取、几何显示和输入。碰撞体仅用于鼠标拾取，当前版本允许肢体互相穿过，不含场景碰撞或关节角度限制。

### 验证

后续修改按用户要求跳过测试阶段，现有测试文件保留。

在 Unity 的 Window → General → Test Runner 中选择 PlayMode，再点击 Run All。
测试覆盖初始静止、原地按住、关节连接、精确跟随、快速拖动、松手冻结，以及实际场景跨帧保持。
